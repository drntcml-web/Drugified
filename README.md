# Drugified — Recovery Together

A social support app for people navigating addiction recovery.

## Setup

1. **Install Node.js** from [nodejs.org](https://nodejs.org) (LTS version)
2. Open Terminal and run:

```bash
cd ~/Desktop/drugified
npm install
npm run dev
```

3. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Pages

| Route | Description |
|-------|-------------|
| `/` | Home — streak counter, mood check-in, daily quote |
| `/feed` | Social feed — post updates, like & support others |
| `/alerts` | Craving log — track triggers and cravings |
| `/resources` | Crisis hotlines, coping tips, articles |
| `/profile` | User profile, milestones, streak progress |

## Login

Use any email + password to log in (mock auth — no backend required).
